## 已执行的机器验证

WorkBuddy 在 2026-11-01 使用 Python 3.13.12 执行：

- `python3 -m compileall -q src`：通过。
- `PYTHONPATH=src python3 -m unittest discover -s tests -v`：12 项全部通过。
- `python3 scripts/generate_examples.py`：成功生成 7 组离线流程记录。
- 使用用户指定的本地服务和 `deepseek-v4.1-flash` 运行 8 组真实模型用例，结果见 `examples/real_manifest.json`。
- 初次真实运行发现连续 JSON 解析失败和一次 gaps 过度推断，已修改实现/协议、增加回归测试并重新运行相关用例。
